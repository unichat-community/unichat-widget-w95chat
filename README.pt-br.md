# UniChat Widget - w95Chat

[🇺🇸 English](./README.md) | [🇧🇷 Português](./README.pt-br.md)

Um widget de chat para o [**UniChat**](https://codeberg.org/unichat/unichat) com tema do Windows 95.

Suporte para os seguintes eventos:
- Remover mensagem
- Remover usuário
- Limpeza de chat
- Mensagem
- Doação (YouTube super chat/sticker, Twitch bits)
- Sponsorship (Membros do YouTube, Inscrição no Twitch)
- SponsorGift (Presente de membro do YouTube, Presente de inscrição no Twitch)
- Raid (YouTube e Twitch)
- Redemption (Resgate de canal do Twitch)

> [!NOTE]
> Assim como qualquer outro widget do **UniChat**, este widget também funciona com fontes originárias de plugins (como a kick por meio do `plugin-kick`),
> porém foi feito primariamente para funcionar com as fontes nativas (YouTube e Twitch), podendo haver limitações e/ou comportamentos inesperados ao utilizar fontes de plugins.
